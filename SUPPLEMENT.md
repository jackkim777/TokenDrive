# Code and Data Supplement

This archive contains the TokenDrive source code, configuration files, scripts, and lightweight data artifacts for the JCDE submission.

The supplement is self-contained as an archive and intentionally does not link to external paper source/data repositories. Large model weight binaries are excluded to keep the package below the submission size limit and to avoid checkpoint metadata disclosure.

Start with `README.md` for installation, training, evaluation, and ablation instructions.
